# Request: download-progress-and-queue

Задача на добавление в UI/OpenComfy:

1. Прогресс-бар для загрузки весов и установки node в интерфейте.
2. Загрузка должна выполняться воркерами, чтобы после перезагрузки страницы прогресс-бар сохранялся — всегда видно, на какой стадии находится загрузка.
3. Веса должны раскладываться по нужных директориям в зависимости от типа модели.
4. Реализовать визуальную очередь (то, что сейчас генерируется в ComfyUI) как в UI, так и в API.

Собрать SDD-задачу на субагентах, показать задачи пользователю, и только после его одобрения запускать выполнение.
